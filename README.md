# StreamScout

Twitch streaming analytics tool that identifies underserved game/category opportunities for streamers.

**Live:** [streamscout.gg](https://streamscout.gg)

**Stack:** Next.js 14, TypeScript, Tailwind CSS, Flask backend (separate repo)

Built in ~15 days by a non-engineer (16-year Amazon PM) using AI-augmented development. Claude Code driving implementation under product direction. No prior coding experience.

~2,100 users and ~6,800 page views since launch.
